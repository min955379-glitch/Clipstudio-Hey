# Decisions

- Started from an empty repository and prioritized an honest, responsive UI prototype. No processing or provider integration is simulated as functional.
- The requested production stack and infrastructure are not yet implemented. The prototype uses Next.js, TypeScript, and Lucide; additional dependencies should be introduced alongside their actual functionality.
- The app uses an original lime-accented visual identity and copy. No reference assets or source code were copied.
- Settings are local-only. Secrets must not be entered until server-side encryption and authenticated storage are implemented.
